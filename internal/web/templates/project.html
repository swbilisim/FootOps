2. Projeyi kontrol et

    {{if eq $in.Kind "nextjs"}}
  • next.config dosyasında output: 'standalone' olmalı (başka ayarlar kalır).
  • Proje kökünde public/ klasörü olmalı; yoksa boş bir tane aç: mkdir public && touch public/.gitkeep
  • Derleme sırasında veritabanı yok: derlenirken veritabanını okuyan sayfaya export const dynamic = 'force-dynamic' ekle.
    • {{else if eq $in.Kind "node"}}
  • Uygulama process.env.PORT'u dinlemeli ve tüm adreslere bağlanmalı: app.listen(process.env.PORT) yeter; 'localhost' ya da '127.0.0.1' verme.
  • Çalışırken gereken paketler dependencies'te olmalı: devDependencies imaja kurulmaz. TypeScript projesinde derlenmiş .js dosyasını başlat (Dockerfile'a derleme adımı gerekir).
  • Sağlık kontrolü / adresine bakar: uygulamanda / yoksa (yalnız API) Dockerfile'daki HEALTHCHECK satırında var olan bir yolu yaz.
    • {{else}} {{if $in.BuildDir}}
  • npm run build çıktıyı {{$in.BuildDir}}/ klasörüne yazmalı.
    • {{else}}
  • Proje kökünde index.html olmalı; klasördeki her şey herkese açık yayınlanır (.dockerignore'dakiler hariç).
    • {{end}}
  • Tek sayfalı uygulamada (React Router gibi) ana sayfa dışındaki adresler doğrudan açılınca 404 verir; böyle bir site için Node.js türünü seç ya da nginx ayarı ekle.
    • {{end}} {{if ne $in.Kind "static"}}

  • Sırlar (JWT_SECRET, API anahtarları, SMTP) .env.local'de kalır, repoya ve imaja girmez; site oluşturulurken panele .env dosyasından ekle ile verilir.

3. GitHub'a gönder

Projenin klasöründe, Terminal'de. GitHub CLI (gh) bir kez kurulup gh auth login ile giriş yapılmış olmalı.

Repo yoksa
git init -b main
git add .
git status
git commit -m "İlk sürüm"
gh repo create {{$in.Owner}}/{{$in.Name}} --private --source . --push
gh run watch

git status'ta .env.local, node_modules{{if eq $in.Kind "nextjs"}}, .next{{end}} listede olmamalı. Son bir bakış: git ls-files | grep -i env{{if $.Data.PublicEnv}} yalnız .env.production (varsa) göstermeli{{else}} boş olmalı{{end}}.

Repo zaten varsa
git add Dockerfile .dockerignore .github/workflows/docker.yml
git commit -m "FootOps: Docker imajı"
git push
gh run watch

Repo GitHub'da {{$in.Owner}} hesabında ve varsayılan dalı main olmalı. Actions kırmızı biterse: gh run view --log-failed.
